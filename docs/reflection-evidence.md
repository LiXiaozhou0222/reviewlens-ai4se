# Reflection Evidence Boundary

`REFLECTION.md` is the student's own required 1,500-2,500 word reflection. The coding agent does not author, expand, or complete that file.

The student should use the real evidence already recorded in `AGENT_LOG.md`, `SPEC_PROCESS.md`, Git history, and test output to describe their own decisions, limitations, interventions, and lessons. This note does not provide reflection prose or a substitute submission.
